Policy pages
============
Put Hudson's approved files here, named exactly:

  privacy-policy.html
  terms-of-service.html
  refund-policy.html

They come from the folder "02 Policy Pages". Use the wording exactly; never edit legal text
without Hudson's sign-off. The page shows only what is inside <main> (or <body>), styled in
the site design. Scripts, styles and forms inside the file are removed.

Until a file is here, its page shows a short "being updated" note with contact details.
